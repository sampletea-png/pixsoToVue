# iterations — skill 自我迭代日志

每次使用 `pixso-to-vue` skill 完成（或中止）一次设计稿转换后，必须在本目录新增一篇复盘日志。

## 命名

```
YYYY-MM-DD-<主题>.md
```

例：`2026-07-26-后台管理首页转换.md`

## 日志格式

```markdown
# <日期> <主题>

## 输入
- Pixso URL / 页面范围：
- skill 版本：

## 结果
- 产出项目路径：
- 转换页面数 / 公共组件数：

## 问题清单（哪一步失真 / 误判 / 返工）
| 阶段 | 问题 | 根因 | 当时如何修复 |
| --- | --- | --- | --- |

## 修订建议
- [ ] 建议沉淀为脚本：<环节> → <拟新增/修改的脚本>
- [ ] 建议修订文档：<文件> → <修订点>

## 已应用的修订
（经用户确认后，记录实际修改了 skill 的哪些文件、version 从 X 变为 Y）
```

## 原则

1. **优先脚本化**：凡是"AI 这次又做错了"的机械性环节，优先写成脚本或增强已有脚本，而不是在文档里多加一句叮嘱。
2. **文档修订要具体**：写明改哪个文件、哪条规则、为什么。
3. **版本递增**：SKILL.md 的 `version` 字段随每次已应用的修订递增，并在日志中记录变更原因。
