## 存疑清单

- 弹窗左栏 DSL 含 10 个 `Header` 节点但截图仅见 8 行，且 `with_drive_event_.04_cycle_2_ start_stop` 文本出现 2 次——疑为选中行重复节点或夹带了隐藏行；Phase 3/6 按截图 8 行实现，TODO 复核。
- 主窗口 Datasets 面板（容器-350）行内数据集名未随 INSTANCE 导出，截图中又被弹窗遮挡（仅见 `Previ…` 截断）——行数据需自行 mock，列头以 DSL 为准（NAME/Fit/Validate，与截图 `Previ…` 列头不一致，存疑）。
- 弹窗无独立遮罩层节点；截图中的压暗效果按 Dialog 遮罩实现即可。
- `+ Add parameters`（参数表头）与 `+ Add parameter`（Curves 头）两处文案近似，功能差异无法从设计稿确认——Phase 7 以合理默认实现 + `TODO: 交互待确认`。
- 工具栏各图标按钮的具体功能（新建/打开/保存/导入/刷新）仅为图标形状推断，低置信度。
- 容器-353 与弹窗右栏图表标题完全相同（`Simulation input curves` / `Signal curve·v_hat_kmh`），两者是否为同一数据的不同视图无法确认；实现上复用同一 `LineChart` 占位组件即可。
