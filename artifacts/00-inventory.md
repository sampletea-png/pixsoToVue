## AI 补全：整体观察

- 产品类型：**桌面工程工具**——「Param Estimation Toolbox - HAS Behavior」（参数估计工具箱），英文 UI，1480×980 左右的桌面窗口形态。
- **关键结构判断**：16 个画板不是 16 个独立页面，而是**同一个应用窗口的不同状态**。已抽查 4 个画板（容器 1/385/439/11）：
  - 共享应用骨架：标题栏（BEH logo + 窗口控制按钮）、工具栏（语言切换等）、左侧导航（Parameters / Ports / Datasets / EstimateResults）、主区 Tab（Convergence Monitor / Report / Simulation response / Parameter Sensitivity / Manual tuning）、底部状态栏（Run 状态 / Algorithm progress）。
  - 差异是状态性的：弹窗开关（Close toolbox 确认框、Parameters 对话框、1D Array Table Editor 嵌套对话框）、对话框空态/填充态、Tab 切换。
  - 推论（置信度：高）：目标应是**单页应用 + 对话框组件 + 页内状态**，路由基本退化为 1–2 条；这将在 Phase 3 架构中定稿。
- 大致模块轮廓（初判，Phase 3 定稿）：单一 `param-estimation` 模块 = 应用骨架（Shell）+ 5 个 Tab 视图 + 若干对话框组件 + 图表区 + 数据表格。
- 设计稿一致性风险：
  - 画板命名无语义（"容器 N"），页面角色必须靠视觉判断；
  - 同一应用中文字/数值为 mock 数据（如 0.9334 重复列、K_brake 重复列名），实现时按示例数据处理即可；
  - 图表（收敛曲线、色谱）为位图/矢量占位，无图表库约定，实现时以占位 + TODO 处理，除非用户指定图表库。
